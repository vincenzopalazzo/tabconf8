# Presenting the TABConf deck: two views

| URL | File | What it shows |
|---|---|---|
| `/` | `index.html` | Projector. Full-bleed slides. Notes are not in this file. |
| `/dev` | `dev/index.html` | Laptop. Slide position, next preview, cue, notes, timer. |

## On stage
1. Open `/dev` in Chrome on the laptop.
2. Press **P** (or click "Open audience window"). That opens `/` in a new window.
   Drag that window to the projector and press **F** for fullscreen.
3. Click back on the speaker window and drive from there. The audience window follows.

## Keys
- Both views: → / Space / PageDown next · ← / PageUp back · Home / End
- Audience: click = next · **F** fullscreen. The cursor is hidden.
- Speaker: **P** open audience window · **T** reset timer (it starts on the first move past slide 1) · **+ / −** notes text size
- Jump to a slide: add `#N` to either URL, for example `/#14` or `/dev/#14`.
